## Release blockers

- Hosted CI must run against the QA-001 changes before those changes can be marked CI verified.
- PILOT-001 is not commercially launch-ready: no approved package/legal terms, support or expiry policy, real merchant acceptance, or confirmed real payment evidence exists. Its local foundation is not proof of a paid pilot.
- Staging OIDC, public domain/TLS, approved Meta assets, AWS/SSM/S3/KMS, alert delivery and an on-call owner remain unavailable, as recorded in the [OPS runbooks](../ops/pilot-deployment.md).
- Live Meta delivery, real model-provider behavior, tenant opt-in, customer opt-out suppression and external policy/legal approvals remain unverified. AI stays disabled by default and additionally requires an operator-approved tenant enrollment.
- Performance sizing and PostgreSQL restart recovery remain not tested; do not infer production SLOs from fixture-suite timing.
